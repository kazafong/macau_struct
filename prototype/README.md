# 澳門 A&A 結構工程草稿原型

本地可點擊的工作流原型，對應同目錄上一層的 `PRD.md` 與 `澳門結構工程服務分析與計劃.html`。這兩個來源檔不會被這個原型修改。

原型裡的草稿代理、付款和簽署都是本地示範：不呼叫外連模型、不扣款、不送到電子簽署服務商，也不會把結果說成主管機關批准或已完成 SAP2000／Excel 整合。

## 再啟動

```bash
cd prototype
python3 server.py
```

或：

```bash
./start.sh
```

瀏覽器打開 [http://127.0.0.1:8765](http://127.0.0.1:8765)。換埠可用 `PORT=8876 python3 server.py`。

產生 PDF 需要本機 Google Chrome。示範圖則在 `sample/macau-aa-sample.dxf`。

## 流程

1. 填設計參數（項目、A／B／C、設計基礎）。
2. 上傳 CAD 類檔案並寫自由文字。文字和檔案只當資料。
3. 本地代理產生結構草稿，工程師逐項複核。
4. 模擬付款（示範金額 MOP 1.00，不是報價，不會扣款）。
5. 在畫布簽名，凍結版本並下載 PDF。
